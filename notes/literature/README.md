# Literature notes

This directory contains notes on literature relevant to grant evaluation,
reviewer variability, statistical modelling, and Bayesian ranking.

One Markdown file is used for each paper. Files are named using the first
author and publication year for example: `kaplan-2008.md`

The notes should focus on understanding the research question, statistical
method, assumptions, findings, and relevance to the current project. They are
working notes and do not need to be written as polished summaries.
