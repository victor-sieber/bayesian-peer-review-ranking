# Bayesian Ranking and Graph-Based Review Design under Sparse Evaluation Data

This repository contains the analysis code, derived results, figures,
documentation and technical report for a statistical re-analysis of the CRS
Seed Grant 2026 evaluation at the Center for Reproducible Science, University
of Zurich.

The project studies two related questions. First, it uses Bayesian hierarchical
models to quantify uncertainty in proposal rankings when each proposal receives
only a small number of reviews. Second, it represents the reviewer--proposal
assignment structure as a bipartite graph and investigates which single
additional review would most reduce posterior uncertainty under the fitted
model.

The main report is:

> **Bayesian Ranking and Graph-Based Review Design under Sparse Evaluation Data: A Case Study of the CRS Seed Grants 2026**

---

# Analysis overview

The primary response variable is the holistic overall grade. The analysis
compares a continuous Heyard reference model (V0) with a CRS-specific
cross-classified model (V1), validates V1, examines the four supporting
criteria, and evaluates hypothetical single additional reviewer--proposal
assignments using A-, D- and E-optimality.

The review-design analysis is retrospective and statistical. Reviewer
expertise, conflicts of interest, availability and other operational
eligibility constraints are not available and are therefore not included in
the candidate assignment set.

# Analysis scripts

| Script | Function |
|---|---|
| `analysis/00_install_heyard_dependencies.R` | Installs required R packages for the Bayesian ranking workflow and installs `ERforResearch` from GitHub when needed. |
| `analysis/01_fit_v0_heyard_reference.R` | Validates the analytical dataset, reconstructs the CRS qualification rule, fits the continuous Heyard reference model V0, and saves posterior summaries, rankings and ranking figures. |
| `analysis/02_fit_v1_cross_classified.R` | Fits the CRS-specific cross-classified Gaussian model V1 with proposal and reviewer effects and saves posterior fits, rankings and uncertainty summaries. |
| `analysis/03_compare_v0_v1.R` | Compares V0 and V1 using posterior-mean ranks, expected ranks, rank uncertainty and pairwise posterior ranking probabilities. |
| `analysis/04_validate_v1.R` | Evaluates V1 computational diagnostics, posterior variance shares and posterior predictive checks. Generates validation figures. |
| `analysis/04b_fit_v1_prior_sensitivity.R` | Refits V1 with alternative half-normal scale priors and compares rankings, uncertainty and variance decomposition with the baseline model. |
| `analysis/04c_investigate_v1_disagreement.R` | Studies reviewer disagreement under V1 using posterior predictive simulations and analytic folded-normal expectations, including continuous and discretized disagreement measures. |
| `analysis/05_analyze_criteria.R` | Analyses the four supporting criteria, computes associations with holistic grades, constructs an equal-weight criterion score and generates descriptive comparisons. |
| `analysis/06_fit_compare_v1_criterion_average.R` | Fits V1 using the equal-weight criterion average as response and compares ranking, uncertainty and variance decomposition with the holistic-grade model. |
| `analysis/06a_visualize_review_graph.R` | Creates an illustrative reviewer--proposal bipartite graph for the graph-based review-design chapter. |
| `analysis/07_single_review_design.R` | Constructs the reviewer--proposal graph, evaluates all 294 possible additional reviewer assignments using posterior-averaged A-, D- and E-optimality, applies rank-one covariance updates and performs posterior-median sensitivity analysis. |
| `analysis/08_visualize_review_design_results.R` | Reads the derived review-design results and creates the A-optimality heatmap used in Chapter 6. It does not access evaluation data or refit models. |

# JAGS model files

- `analysis/model/model_v0_heyard_reference.txt`  
  Continuous V0 reference specification following the Heyard modelling framework.

- `analysis/model/model_v1_cross_classified.txt`  
  Main CRS-specific crossed proposal--reviewer hierarchical model.

- `analysis/model/model_v1_halfnormal_sensitivity.txt`  
  Sensitivity specification using alternative half-normal scale priors.

# Suggested analysis order

Run scripts from the repository root.

The main dependency order is:

```text
00_install_heyard_dependencies.R
01_fit_v0_heyard_reference.R
02_fit_v1_cross_classified.R
03_compare_v0_v1.R
04_validate_v1.R
04b_fit_v1_prior_sensitivity.R
04c_investigate_v1_disagreement.R
05_analyze_criteria.R
06_fit_compare_v1_criterion_average.R
06a_visualize_review_graph.R
07_single_review_design.R
08_visualize_review_design_results.R
```

Scripts `03`, `04`, `04c`, `07` and `08` use derived outputs from previous
analysis stages rather than refitting the main Bayesian models.

Large posterior fit objects are reproducible intermediate files and are
excluded from version control through `.gitignore`.

# Software

The analysis is written in R and uses JAGS for Bayesian model fitting.

Main R packages include:

- `runjags`
- `ERforResearch`
- `coda`
- `dplyr`
- `tidyr`
- `ggplot2`
- `ggrepel`
- `tibble`
- `igraph`

The model-fitting scripts currently expect a Homebrew JAGS installation at:

```
/opt/homebrew/bin/jags
```

This path should be adjusted if JAGS is installed elsewhere.

Package and session information for the main fits is stored together with the
corresponding derived results.

# Data availability and protection

Evaluation data are not stored or version-controlled in this repository.

During development, the analytical dataset is kept locally or in approved UZH
storage and excluded through `.gitignore`.

The finalized anonymized dataset is intended to be archived separately on
Zenodo. Once released, the corresponding citation and persistent identifier
will be added here.

Qualitative free-text responses, direct identifiers and re-identification keys
are not intended for publication.
